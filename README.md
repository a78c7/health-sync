# HealthHook 健康同步

把 Apple 健康数据自动、增量地 POST 到你自己设置的 Webhook。免费、开源，数据从 iPhone 直接发到你填的地址，中间没有任何开发者服务器。

HealthHook pushes your Apple Health data to your own webhook, incrementally and automatically, with no middleman server.

> 开发中，还不能用。计划和进度见 [docs/PLAN.md](docs/PLAN.md)。

- 平台：iOS 17 及以上
- 技术：Swift 6、SwiftUI、HealthKit，无第三方依赖
- 许可：[MIT](LICENSE)
